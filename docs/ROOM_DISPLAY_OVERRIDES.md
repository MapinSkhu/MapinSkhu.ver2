## 실제 데이터가 변경됐을 때 점검 순서

1. CSV/DB에 새천년관 B2의 실제 호실이 추가되면 `VIRTUAL_BUILDING_ROOMS`의 대응 가상 공간을 먼저 제거한다. 그렇지 않으면 같은 공간이 중복 표시될 수 있다.
2. 8102, 8103, 8202, 8203 또는 8303을 다시 새천년관 화면에 보여야 한다면 `BUILDING_PAGE_HIDDEN_ROOMS`에서 해당 번호를 제거한다.
3. 중앙도서관 데이터를 새천년관과 분리해야 한다면 `BUILDING_PAGE_EXTRA_SOURCES`에서 `중앙도서관`을 제거한다.
4. M809/M814 이외의 공간을 F5~F8에 보여야 한다면 `MGELL_UPPER_VISIBLE_ROOMS`를 수정한다.
5. 공유 사진 대상에 실제 개별 사진이 생기면 `SHARED_IMAGE_ROOMS`에서 해당 호실을 제거한다.
6. 9101/9301의 공식 명칭이 원본 데이터에 반영되면 `ROOM_DISPLAY_NAMES`와 중복 여부를 확인한다.
7. 일만관 5층 공간의 강의실 여부가 공식 데이터 필드로 구분되면 `CLASSROOM_CLASSIFICATION_OVERRIDES`를 제거하고 공식 필드를 사용한다.
