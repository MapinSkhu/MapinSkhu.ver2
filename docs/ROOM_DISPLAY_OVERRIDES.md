## 실제 데이터가 변경됐을 때 점검 순서

1. CSV/DB에 새천년관 B2의 실제 호실이 추가되면 `VIRTUAL_BUILDING_ROOMS`의 대응 가상 공간을 먼저 제거한다. 그렇지 않으면 같은 공간이 중복 표시될 수 있다.
2. 새천년관의 기계실이 실제로 B2에 있는지 확인하고, 위치가 공식 데이터와 일치하는지 검증한다.
3. 8102, 8103, 8203 또는 8303을 다시 새천년관 화면에 보여야 한다면 `BUILDING_PAGE_HIDDEN_ROOMS`에서 해당 번호를 제거한다.
4. 중앙도서관 데이터를 새천년관과 분리해야 한다면 `BUILDING_PAGE_EXTRA_SOURCES`에서 `중앙도서관`을 제거한다.
5. M809/M814 이외의 공간을 F5~F8에 보여야 한다면 `MGELL_UPPER_VISIBLE_ROOMS`를 수정한다.
6. 공유 사진 대상에 실제 개별 사진이 생기면 `SHARED_IMAGE_ROOMS`에서 해당 호실을 제거한다.
7. 9101/9301의 공식 명칭이 원본 데이터에 반영되면 `ROOM_DISPLAY_NAMES`와 중복 여부를 확인한다.
8. 일만관 5층 공간의 강의실 여부가 공식 데이터 필드로 구분되면 `CLASSROOM_CLASSIFICATION_OVERRIDES`를 제거하고 공식 필드를 사용한다.
9. 8202의 공식 명칭이 `라운지`로 변경되면 `BUILDING_PAGE_DETAIL_OVERRIDES`에서 해당 예외를 제거한다.
10. 월당관 3103·3104와 3201·3202의 공식 명칭이 구분되면 `BUILDING_PAGE_DETAIL_OVERRIDES`의 월당관 예외를 제거한다.
11. 월당관 3103·3104의 공식 공간 분류가 강의실로 반영되면 해당 `CLASSROOM_CLASSIFICATION_OVERRIDES` 예외를 제거한다.
12. 월당관 3102를 다시 표시해야 하면 `BUILDING_PAGE_HIDDEN_ROOMS`의 월당관 목록에서 제거한다.
13. 나눔관 5C202·5C203·5C206을 다시 표시해야 하면 `BUILDING_PAGE_HIDDEN_ROOMS`의 나눔관 목록에서 제거한다.
14. 2A501A의 공식 용도가 `강사실`로 반영되면 `BUILDING_PAGE_DETAIL_OVERRIDES`와 `NON_CLASSROOM_CLASSIFICATION_OVERRIDES`에서 해당 예외를 제거한다.
15. 일만관의 공식 호실명과 수업 데이터가 모두 `2B105` 또는 모두 `B105`로 통일되면 `2B105/B105` 매칭 및 강의실 분류 예외를 제거하거나 단순화한다.
16. 새천년관의 공식 호실명과 수업 데이터가 모두 `7202~3` 또는 단일 호실명으로 통일되면 `7202~3` 매칭 예외를 제거하거나 단순화한다.
17. `7706 세미나 실습실`의 공식 공간 분류가 강의실로 반영되면 해당 `CLASSROOM_CLASSIFICATION_OVERRIDES` 예외를 제거한다.
18. `9301 성미가엘성당`의 공식 공간 분류가 강의실로 반영되면 해당 `CLASSROOM_CLASSIFICATION_OVERRIDES` 예외를 제거한다.
19. 승연관 F3·F4 또는 일만관 F2·F3·F4의 교수연구실을 다시 개별 카드로 표시해야 하면 `BUILDING_PAGE_PROFESSOR_ROOM_FLOORS`에서 해당 층을 제거한다.

### 정적 이미지 통합 단계

- [x] 1단계: `python manage.py audit_room_images`로 각 호실을 `정적+media`, `정적만`, `media만`, `둘 다 없음`으로 구분하고, 양쪽 사진의 SHA-256 동일 여부 및 1MB 초과 최적화 후보를 자동 점검할 수 있게 한다.
- [x] 2단계: `media`에만 있는 실제 사진을 점검한다. 현재 유효한 `media_only` 사진은 0개이므로 이전할 파일이 없으며, `imagewait`와 `nonimage` 같은 기본 이미지는 이전 대상에서 제외한다.
- [x] 3단계: 호실 사진과 공용 기본 이미지 파일명을 소문자로 정규화하고 확장자 정책을 정한다. JPEG 파일은 `.jpg`, PNG는 `.png`, 향후 최적화 파일은 `.webp`를 사용하며 확장자는 모두 소문자로 관리한다. Linux 배포 환경에서도 같은 경로로 탐색되도록 기존 대문자·`.jpeg` 호실 파일 28개와 `nonImage.png`를 정규화했다.
- [x] 4단계: 여러 호실이 같은 사진을 쓰는 경우 실제 화면에서는 파일을 복제해 연결하지 않고 `SHARED_IMAGE_ROOMS`에서 공유 관계를 관리한다. 9202~9204는 9201 사진을, 8b102는 8b101 사진을 사용하며 자기 자신을 가리키는 불필요한 매핑은 제거했다. 코드에서 참조하지 않는 동일 내용의 과거 중앙도서관·피츠버그홀 파일 5개는 `중앙도서관.jpg` 한 장만 원본으로 보존하고 나머지 중복 사본 4개를 정리했다.
- [x] 5단계: 관별 카드, 강의실 상세, 검색 결과가 모두 `classApp/static/images/classroom/`의 정적 이미지를 우선 사용하도록 검증하고 `Room.room_image`를 사용하는 화면 fallback 로직을 제거했다. 정적 사진이 없는 강의실은 `imagewait.png`, 특수목적실은 `nonimage.png`를 표시하며, 메인 화면을 열 때 정적 이미지를 DB media로 복사하던 과거 초기화 로직도 제거했다. DB 필드와 media 파일 자체는 6단계 전까지 보존한다.
- [ ] 6단계: 일정 기간 누락 여부를 확인하고 DB와 media를 백업한 뒤, 더 이상 필요하지 않은 `room_image` 필드와 media 파일 정리를 검토한다.
